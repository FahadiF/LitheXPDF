      READER PREFERENCES

      Options

      Page rendering

      The encoded page cache is capped at 64 MiB and 30 pages. Only the active document is preloaded; inactive tabs keep metadata only and render after you switch to them. Changing to No preloading clears existing prefetched pages. Higher settings use more background CPU and can use more memory; these limits are initial targets, not measured savings.

      QUICK GUIDE

      Help

      • Open PDFs with Ctrl + O; each document opens in a tab.
      • Use the page field, Previous/Next, or scroll through the document.
      • Print opens the system print dialog for the displayed page; printer and paper options depend on the selected printer. All-page and page-range printing are not available yet.
      • Recent file paths are stored locally in this browser profile. Background tabs keep only their file path and view position. The worker opens one PDF at a time.
