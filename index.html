      READER PREFERENCES

      Options

      Page rendering

      On by default. Renders at up to 2× display density for clearer text and fine details. It may take longer and use more image-cache memory. The worker's bitmap and image-size limits still apply; Speed uses standard display density.

      Default. Begins in the background shortly after opening, then keeps nearby pages ready as you scroll.

      Highest background CPU and cache use. It fills a rolling window; it does not render every page of a long document at once.

      Session

      When enabled, all open tabs and your position in each document are saved automatically. The next time you launch LitheXPDF, they are restored. Disabling this clears the saved session.

      Cache memory limits & policy

      Only the active document is prepared; background tabs keep metadata only. The rolling cache is capped at 64 MiB of encoded page data, 64 MiB of estimated decoded pixels, and 30 page images. Larger budgets use more background CPU and memory. These are enforced limits and estimates, not measured system-memory savings.

      WINDOWS FILE ASSOCIATION

      Make LitheXPDF your default PDF app?

      QUICK GUIDE

      Keyboard Shortcuts & Help

      • Open PDF: Ctrl + O — Opens one or more documents in tabs.
      • New Tab: Ctrl + T — Open another PDF in a fresh tab.
      • Close Tab: Ctrl + W — Close the active document tab.
      • Navigation: Use the Previous/Next buttons, left/right arrow keys, mouse wheel, or page number field.
      • Zoom: Ctrl + + and Ctrl + - to zoom in or out.
      • Rotate: Use the rotate buttons to change the active tab’s viewing angle. Rotation is saved with the tab and does not modify the PDF; printing keeps the file’s original orientation.
      • Find in Document: Search text across the PDF. Scanned pages without a text layer are not searchable.
      • Tabs: Only one document is open in the native PDF renderer at a time. Background tabs retain their path and view state.
      • Print: Ctrl + P opens LitheXPDF page selection, with the document page count shown for range entry. Choose the current page, all pages, or a range; then select a printer, paper size, orientation, and printer properties in Windows.
      • Help: Press F1 to open this guide.
