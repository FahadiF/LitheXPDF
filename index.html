      READER PREFERENCES

      Options

      Page rendering

      The encoded page cache is capped at 64 MiB and 30 pages. Only the active document is preloaded; inactive tabs keep metadata only and render after you switch to them. Changing to No preloading clears existing prefetched pages. Higher settings use more background CPU and can use more memory; these limits are initial targets, not measured savings.

      QUICK GUIDE

      Keyboard Shortcuts & Help

      • Open PDF: Ctrl + O — Opens one or more documents in tabs.
      • New Tab: Ctrl + T — Open another PDF in a fresh tab.
      • Close Tab: Ctrl + W — Close the active document tab.
      • Navigation: Use the Previous/Next buttons, left/right arrow keys, mouse wheel, or page number field.
      • Zoom: Ctrl + + and Ctrl + - to zoom in or out.
      • Rotate: Use the rotate buttons to change the active tab’s viewing angle. Rotation is saved with the tab and does not modify the PDF; printing keeps the file’s original orientation.
      • Find in Document: Search text across the PDF. Scanned pages without a text layer are not searchable.
      • Tabs: Only one document is open in the native PDF renderer at a time. Background tabs retain their path and view state.
      • Print: Ctrl + P prints the current rendered page.
      • Help: Press F1 to open this guide.
