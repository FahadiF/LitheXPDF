# Security Policy

## Supported versions

LitheXPDF is in early development. The `v0.1.0` Windows x64 MSI is a preview for evaluation, not a supported stable release. Security fixes are made against the current default branch. No stable release is supported until the compatibility, installer, and release gates in `docs/TESTING.md` are complete.

## Reporting a vulnerability

Do not post exploit details or unpatched vulnerabilities in public issues or pull requests. Use GitHub's private vulnerability reporting if it is enabled for this repository. If it is unavailable, email [contact@fahadibnefahian.com](mailto:contact@fahadibnefahian.com) to request a private reporting channel; do not send sensitive exploit details or personal PDFs in an initial email. Avoid including personal PDFs or other private documents in reports unless a minimal, sanitized fixture is sufficient.

There is no formal response-time commitment or bug bounty at this stage.
