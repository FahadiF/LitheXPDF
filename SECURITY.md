# Security Policy

## Supported versions

LitheXPDF is in early development and has no supported release builds. Security fixes are made against the current default branch; no packaged release should be treated as supported until the release and compatibility gates in `docs/TESTING.md` are complete.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository from the **Security** tab when that feature is available. Do not post exploit details or unpatched vulnerabilities in public issues or pull requests. If private reporting is unavailable, contact the maintainer privately through the GitHub profile and ask for a secure reporting channel. Avoid including personal PDFs or other private documents in reports unless a minimal, sanitized fixture is sufficient.

There is no formal response-time commitment or bug bounty at this stage.
